## 🧠 学习方法：苏格拉底式笔记

每个项目不是看一遍就过，而是三步深入：

| 步骤 | 方法 | 核心动作 |
|:--|:--|:--|
| **① 抓骨架** | 剥离细节，还原设计者的核心问题 | 画结构图，找核心假设，标注数据流 |
| **② 找争议** | 找论文避而不谈的点、作者的取舍 | 对比同类方案，找到"为什么不是 XXX" |
| **③ 被拷问** | 站在设计者角度回答尖锐问题 | 自问自答，直到能用一句话说清本质 |

📂 笔记已迁移至 [private 仓库](https://github.com/laohao78/robotics-notebook)
